- `business-card-back.png` — dark side: pitch + service area + QR to
  `https://www.anjconstruction.co/` ("Get a free quote")

## Print spec (give this to the shop or use on VistaPrint)

- Standard business card, 3.5 x 2 in finished, double-sided
- Stock: 16pt, **matte** finish (matte scans better than gloss)
- Quantity: 250-500 of each to start

## Notes

- Both QR codes were machine-verified from the final artwork. If either link
  ever changes, regenerate the cards; never print old stock with a dead link.
- Test-scan a printed card with a phone before handing any out.
- There is no phone number on these cards on purpose (no dedicated line yet).
  When the business gets one, regenerate both cards with it.
