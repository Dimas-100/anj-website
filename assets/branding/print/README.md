# ANJ review cards — print files

Double-sided business card. Hand one to the client when the job wraps up.

- `review-card-front.png` — dark side: "How did we do?" + QR code
- `review-card-back.png` — red side: ANJ lockup

## Print spec (give this to the shop or use on VistaPrint)

- Size: standard business card, **3.5 x 2 in** finished
- Files are **3.75 x 2.25 in at 300 DPI** (1/8 in bleed on every side already included)
- Double-sided, front = dark card, back = red card
- Stock: 16pt, **matte** finish (matte scans better than gloss)
- Quantity: 250-500 to start

## Notes

- The QR code points to the Google review link
  (`https://g.page/r/CWqrkfjS4WBDEBM/review`) and was machine-verified from the
  final artwork. If the review link ever changes, regenerate the cards; never
  print old stock with a dead link.
- Test-scan a printed card with a phone before handing any out.
